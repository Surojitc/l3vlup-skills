# Investment Banking — L3VLUP Skills

The deliverables chain a banking analyst lives in — profiles, comps, books, models.

| Skill | Job to be done | Output | Time |
|---|---|---|---|
| [Company Profile](./company-profile/SKILL.md) | Build a banker-grade one-pager on any company, fast. | Company one-pager (profile page inputs) | ~25 min |
| [Comps Set Builder](./comps-set-builder/SKILL.md) | Choose a defensible comparable-companies universe, and be able to defend every inclusion. | Comps universe table + inclusion rationale | ~30 min |
| [Model Audit](./model-audit/SKILL.md) | Find the errors in a financial model before someone senior does. | Structured error/risk report | ~45 min |
| [Meeting Prep](./meeting-prep/SKILL.md) | Walk into any client, management or interview meeting knowing the company, the people and the agenda cold. | Meeting brief: company, people, agenda, questions | ~30 min |
| [Pitchbook QC](./pitchbook-qc/SKILL.md) | Catch the errors in a pitchbook before it leaves the building. | QC issue list by page | ~20 min |
